# Security scope

Checks are read only. Repair writes only `HKCU\Environment\Path`, preserves its raw value and registry type, and keeps a local backup for conditional restore. The installer runs only after confirmation and uses fixed official HTTPS script URLs. No credential access, machine PATH write, elevation, or execution-policy change is present. `ProcessRunner` uses `UseShellExecute = false`, `ArgumentList`, bounded output, and timeouts. Raw installer output is retained only in memory and is not shown or shared; Windows report export remains open.

The macOS shareable report includes check results and the last operation error. It replaces home-directory paths with `$HOME` and excludes raw command output and the full PATH. Users choose when to copy or save it.

After AGY installation passes version verification, the app opens the official interactive AGY setup in a separate terminal. It also offers a button for existing installations. Authentication, authorization codes, and theme choices stay in AGY and the browser; AGY Ready does not read or store them. The first-run process starts in a dedicated application folder so workspace trust applies only to that folder. Other project folders still require their own trust decision.

The clasp install action runs the fixed `npm install @google/clasp -g` command after explicit confirmation. It does not read Google credentials or display raw npm output. A successful npm exit code alone is not treated as a successful clasp setup. A separate user-initiated login button opens a command window for `clasp.cmd login`; authentication stays in that window and the browser, and the app does not capture its output.

The optional PowerShell clasp repair changes only the Windows PowerShell `CurrentUser` execution policy from `Restricted` or `Undefined` to `RemoteSigned`, after a warning and explicit confirmation. It checks Group Policy and process scope first, then verifies bare `clasp --version` in a fresh PowerShell process. If verification fails, it attempts to restore the previous `CurrentUser` value and reports if restoration cannot be confirmed. This user-wide setting affects other PowerShell scripts; `clasp.cmd` is the no-policy-change alternative.
